# Разборка v3 — «плоский срез + квадратный шип» (как у профи)

Кодовое слово: **«кит»** (от garage kit; синонимы — «гаражный кит», «на шипах»).
Основано на разборе 6 профессиональных моделей — [`../../reference_examples/АНАЛИЗ_CULTS.md`](../../reference_examples/АНАЛИЗ_CULTS.md).
Общие правила из `CLAUDE.md` действуют: 3D не перегенерировать, список деталей согласовать, мастер 10 см, крепёж — в итоговом размере.

## Суть

Каждый стык — **одна ровная плоскость по краю одежды** + **один квадратный шип** из внутренней детали в наружную.
Деталь = один цвет/материал. Никаких волнистых границ и круглых штырей.

## Шаг 1. Список деталей (согласовать, без «да» не резать)

**Полный каталог элементов — [`ЭЛЕМЕНТЫ.md`](ЭЛЕМЕНТЫ.md)**: что выделяют в деталь, что с чем остаётся, где шов, где резать нельзя.
Шов = место, где один элемент входит в другой: меняется цвет/материал **и** есть ступенька формы. Цвет на гладком — красим.
Скилл Claude Code — `.claude/skills/kit/SKILL.md`.

Шаблон персонажа — режем **только там, где меняется цвет И есть край объёма**:

| Зона | Как делить | Где плоскость |
|---|---|---|
| Лицо | отдельно от волос всегда; шея идёт с лицом | за ушами / по линии волос; на спинке — большой квадратный блок в карман волос |
| Волосы | 2–4 детали: масса сзади, чёлка, каждая выступающая прядь / хвост / коса | у основания каждой пряди; симметричную массу можно пополам вертикально |
| Головные уборы, банты, заколки | отдельно | по месту посадки |
| Шея → торс | | по воротнику / вырезу; плоскость на 1–2 мм внутри воротника |
| Верх → низ | | по поясу / ремню (ремень остаётся на верхней детали или отдельной накладкой) |
| Накидка, капюшон, жилет поверх торса | отдельная оболочка; торс под ней можно упростить | по нижнему краю накидки |
| Рука | **рукав того же цвета, что кофта, остаётся на кофте**. Короткий рукав → «рука от края рукава до пальцев» одной деталью. Длинный рукав другого цвета → рукав+рука от плеча | по краю рукава / по шву плеча |
| Кисть | отдельно **только если другого цвета**, чем рукав (перчатка, кожа против ткани). Держит предмет → кисть вместе с предметом | по манжете, запястье входит в рукав |
| Ноги | от подола юбки/шорт до подошвы **одной деталью**, если чулок/сапог продолжает ногу одним объёмом | по подолу; плоскость на 1–3 мм выше подола, под юбкой |
| Обувь | отдельно **только при явном крае** (верх голенища, отворот, другой цвет и объём) | по верху голенища |
| Подставка | всегда отдельно | по подошве |
| Длинный предмет (посох, меч) | куски 50–90 мм в итоговом размере (на 40-мм фигурке обычно целиком) | там, где сменяется деталь (навершие, гарда) |
| Тонкие накладки (ремни, ленты, пуговицы) | отдельно, на клей | — |

Спорные места (сапог вместе с ногой или отдельно, кисть отдельно или нет) — вынести вопросом в список.

## Шаг 2. Плоскости (на мастере 10 см)

1. На каждый стык — **одна плоскость** (точка + нормаль). Для конечности нормаль = ось конечности у стыка, для пояса/подола — горизонталь.
2. Видимая линия шва = край одежды. Если над стыком есть нависающий край (подол, манжета, воротник) — плоскость **прячем под него на 1–3 мм**.
   Если нависания нет — плоскость ровно по складке/шву модели.
3. Резать **локальным резаком**, а не плоскостью через всю фигурку: резак = призма вдоль оси конечности с сечением конечности (+0,4 мм),
   закрытая плоскостью стыка (`prism` в плане). Так юбка/куртка сохраняет свой нависающий подол, а ноги уходят под неё ровным торцом
   и садятся в гнездо. Для кистей, кроссовок — `box`/`cyl` вокруг детали.
   Сложный стык (голова на капюшоне) — объединение областей (`any`): например, шея-пробка в воротник + наклонная плоскость над капюшоном.
4. Порядок «снимаем с краёв к центру»: подставка → обувь → ноги → кисти → руки → голова (волосы, лицо) → накидка → верх / низ.
   Каждый шаг: `деталь = тело ∩ резак`, `тело = тело − резак` (булевы операции по сетке, `manifold3d`) — грани получаются идеально плоскими.
5. Показать схему плоскостей (4 вида с линиями швов) и вид «в разборе» → ждать «ок».
6. Сохранить мастер-детали `master_100mm/` без шипов.

## Шаг 3. Шипы (только в итоговом размере, в мм итоговой фигурки)

- Форма: квадрат (или прямоугольник по форме среза), рёбра скруглены r 0,3 мм, уклон стенок ~4° (сужается к торцу).
- Ширина: **35–45 % меньшей стороны среза**, вокруг гнезда стенка ≥ 0,6 мм и дно ≥ 0,6 мм (смола, 40 мм; у профи на тонких
  стыках 0,5–0,9 мм) / ≥ 1,5 мм (фигурки 10+ см). Минимум 1,0 мм. Не влезает — без шипа, на клей (скрипт пишет это сам).
- Высота: **0,8 ширины**, но гнездо не глубже половины толщины детали-получателя (чтобы с другой стороны влез свой шип).
  Подставка → подошвы — «установочные» шипы пониже (`kh: 0.5`).
- Порядок: сначала несущие внутренние стыки (голова, кисти, ноги в куртку), потом внешние (обувь, подставка) — им достаётся оставшееся место.
  Скрипт пробует несколько точек среза, если центр занят чужим гнездом.
- Чей шип: из **внутренней** детали в **наружную** (нога → юбка, шея → воротник, запястье → рукав, лицо → волосы, таз → торс).
  Подставка — шипы из подставки в подошвы.
- Центр — в центре среза, стороны квадрата — по главным осям среза. Один шип на стык.
- Зазоры (смола): плоскость **0** (впритык), стенки гнезда **+0,1 мм** на сторону, торец **+0,25 мм**. FDM: стенки +0,2, торец +0,3.
- Полость (если фигурка больше ~8 см): стенка 1,2–2 мм, полость открыта в плоскость среза или в дно, шип сплошной.

### План (`plan.json`)

```json
{"master": "master.stl", "rest": "jacket",
 "parts": [
  {"name": "base", "planes": [{"p": [0,0,7.15], "n": "-z"}], "seed": [0,0,3], "key": "part", "kh": 0.5},
  {"name": "hand_left", "planes": [{"p": [-19,-4,29.5], "n": "-z"}], "box": [[-27,-11,15],[-13.5,3.5,40]],
   "seed": [-19,-4.5,25], "key": "part"},
  {"name": "pants", "any": [
     {"planes": [{"p": [0,0,27], "n": "-z"}], "prism": {"at": [0,0,22.5], "axis": "z", "margin": 0.4, "pick": [0,0,22.5]}},
     {"planes": [{"p": [0,0,19], "n": "-z"}]}], "seed": [-6,0,20], "key": "part"}
 ]}
```
- `planes`: точка + нормаль, **нормаль смотрит внутрь снимаемой детали**; первая плоскость — плоскость стыка (на ней шип).
- Ограничители области: `cyl` (цилиндр), `box`, `sphere`, `prism` (сечение тела в точке `at` + `margin`, вытянутое по оси), `any` — объединение областей,
  `ellipsoid` (снаружи/внутри черепа — для шапок, волос, масок), `minus` — вычесть области (пробка ноги в ботинке).
- `seed: "all"` — деталь из нескольких кусков (пряди чёлки).
- `seed` — точка внутри детали (берётся только её кусок, остальное возвращается телу).
- `key`: `part` — шип из этой детали в соседа, `body` — из соседа в неё, `none` — клей; `kh` — высота шипа / ширина.
- Порядок деталей = порядок снятия: от краёв к центру (подставка → обувь → ноги → кисти → лицо → волосы), остаток = `rest`.

Полный пример со всеми приёмами — `examples/emm_plan.json` (Эмм, собрана в коде: `print/emm/src/build_emm.py`).

Уроки первого прогона (`examples/puffer_guy_plan.json`):
- плоскость подставки ставить **чуть выше** её верха (верх у ИИ-моделей неровный ±0,2 мм), иначе плёнка подставки уезжает в обувь;
- призма по сечению берётся там, где деталь ещё отдельна (штаны — ниже подола, но ноги внизу шире → добавить вторую область `any`);
- голова, сросшаяся с капюшоном, снимается наклонной плоскостью: спереди внутри воротника, сзади над капюшоном.
