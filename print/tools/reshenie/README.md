# «Разборка с решением» — протокол

Кодовое слово: **«решение»** в любой форме («разборка с решением», «по решениям», «решительно»).
Отличие от обычной разборки (`split.py` по разметке спереди): детали размечаются **на самой 3D-модели со всех сторон** —
по **цвету текстуры** и по **швам/складкам объёма** (вогнутость поверхности), а не по 2D-картинке.
Эталон результата: `print/redhead_black_tracksuit_parts/` (12 деталей).

## Шаги

1. **Цвета на модели.** Нужна 3D с текстурой. Если модель уже есть без цвета — цвета бесплатно проекцией с референса
   (не перегенерировать). `load.py`: Z вверх, лицо → −Y, мастер 100 мм, цвет каждой грани из текстуры, вершины сшиваются.
2. **Классы цвета** (`classify` в `load.py`): кожа / волосы / одежда / платформа (платформа — всё ниже её верхней плоскости).
3. **Карта швов.** Сглаженная вогнутость граней (`conc.npy`), режим `MODE=abs` — ловит смоделированные швы
   (реглан, подол, манжеты, край штанин). Посмотреть картинкой перед разметкой.
4. **Семена деталей.** На видах спереди/сзади (сплэт 0,2 мм/пикс) поставить по точке на деталь + наборы граней-опор
   там, где граница неочевидна (спина под реглан, сиденье для штанин, шея = кожа у воротника).
5. **Рост областей** (`seg_redhead.py` как пример): многоисточниковая Дейкстра по графу граней,
   цена ребра = длина × (1 + K·|вогнутость|), смена цвета +60 → границы сами ложатся в швы и на переходы цвета.
   Потом: сглаживание границ одежды (диффузия меток, не через цвет), волосы строго по красному (крупнейшая компонента + дыры в ней),
   уши → голова, шея = только цилиндр под подбородком.
6. **Показать покраску** (`labels_views.py`): 4 вида + легенда — ждать «ок» или правок. Не резать без подтверждения.
7. **Мастер-воксели** (`mesh2vox.py`, шаг 0,1 мм): поверхность → заливка → внутренность по ближайшей метке,
   волосы не толще 6 мм (глубже → голова), платформа строго ниже верха, сглаживание σ 0,5 мм, одно тело на деталь.
   → `labels.npz` + `master_100mm/*.stl`. Потом `fixneck.py` (шея не уходит пробкой в тело/голову),
   `flatten_base.py` (ровное дно платформы).
8. **Итоговый размер** — `../finalize.py` по группам (`ONLY=...`, иначе не хватает памяти), штыри только на основных стыках:
   `PEGS="shoe_left-platform,shoe_right-platform,shoe_left-pant_left,shoe_right-pant_right,pant_left-pant_right,pant_left-body,pant_right-body,sleeve_left-body,sleeve_right-body,body-neck,neck-head,head-hair" GLUE=hands`.
9. **Надпись «Ortho Pop»** на дне платформы — `../engrave.py platform.stl ../orthopop_logo.png out.stl 20 0.4 0.05 <центр_y>`.
10. **Сохранение** — как в обычной разборке: `clean_parts.py`, файлы < 100 МБ (досжать с проверкой замкнутости),
    `preview.png` (`explode_preview.py`, `HAIR=r,g,b`), `labels_3d.png`, `СБОРКА.md`, `update_table.py`, коммит, пуш.

## Под нового персонажа

В `seg_redhead.py` (скопировать под имя) поправить: список `NAMES`, координаты семян, правила классов цвета,
