# Инструменты «разборки»

Запускать из корня репозитория. Нужны: `pip install trimesh scipy scikit-image fast_simplification matplotlib pillow`.

| Скрипт | Что делает |
|---|---|
| `hollow.py in.glb out.stl [высота=40] [стенка=1.5] [слив=2.5]` | Целая полая модель: масштаб, закрытие дыр, полость, сливное отверстие в дне. |
| `split.py model.glb разметка.jpg cutdir` | **Шаг 1 — нарезка на мастере.** Детали по разметке, сглаженные границы, очки/глаза по рельефу, ровный галстук. Сетка 0,04 мм на эталоне 40 мм = 0,1 мм на мастере 10 см. Пишет `cutdir/labels.npz` и `cutdir/master_100mm/*.stl` (без штырей). `PITCH=0.1` — быстрый черновик, `LABELS_ONLY=1` — только метки. |
| `finalize.py cutdir/labels.npz outdir [высота=40]` | **Шаг 2 — итоговый размер.** Штыри/гнёзда, полости, сливы — в мм итоговой фигурки. `CLEAR=0.15` (FDM 0.25), `WALL=1.2`, `PEG=2.0`, `GLUE=glasses,eyes,tie,shirt`. Проверяет, что полость открыта, иначе делает деталь сплошной. |
| `front_labels.py outdir/_lab3.npy front.png [масштаб]` | Схема цветов деталей спереди (быстрая проверка разметки). |
| `engrave.py in.stl print/tools/orthopop_logo.png out.stl [ширина=20] [глубина=0.4] [срез_дна=0.35] [центр_y=1.5]` | Гравировка надписи «Ortho Pop» на дне: выравнивает дно, вырезает надпись (читается при взгляде снизу). Нужны `manifold3d shapely mapbox_earcut`. |
| `clean_parts.py outdir` | Убирает обрывки, ужимает STL без потери замкнутости. |
| `explode_preview.py outdir preview.png` | Картинка «в сборе / в разборе». |

## Параметры по умолчанию

- Нарезка: воксель 0,1 мм на мастере 10 см (0,04 мм на 40 мм). Штыри/зазоры/стенки — в итоговом размере.
- Штырь Ø2 × 2 мм, радиальный зазор гнезда 0,15 мм (смола). Для FDM брать 0,25.
- Стенка полых деталей 1,2 мм; полость только у деталей > 80 мм³.
- Стыки < 8 мм² и тонкие накладки (очки, глаза, галстук, воротник) — на клей.

## Под нового персонажа

В `split.py` поправить список `NAMES`, правила распознавания цветов разметки
(какой цвет → какая деталь по положению) и блок «чистовая доводка»
(какие накладки брать по рельефу, какие строить ровной формой).
