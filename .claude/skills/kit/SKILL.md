# «Кит» — разборка как у профи

Каждый стык = **одна ровная плоскость по краю одежды** + **один квадратный шип** из внутренней детали в наружную.
Деталь = один материал/цвет. Образец — 6 профессиональных моделей, разобранных в
`print/reference_examples/АНАЛИЗ_CULTS.md`. Скрипты — `print/tools/razborka_v3/` (подробно — `README.md` там же).

**Перед работой прочитать** `print/tools/razborka_v3/ЭЛЕМЕНТЫ.md` — каталог: что выделяют в деталь (волосы, лицо, руки, верх,
низ, обувь…), что с чем остаётся и где именно шов. Правила `CLAUDE.md` действуют: модель не перегенерировать, кредиты — только с «да».

## Где шов (самое важное)

Шов там, где **один элемент входит в другой**: рука из рукава, ноги из-под юбки, шея из воротника, кисть из манжеты, коса из головы.
Нужны оба признака: **меняется материал/цвет** И **есть ступенька формы** (нависающий край, борозда, перетяжка).
- Цвет меняется на гладком месте (вырез платья, верх чулка, край перчатки, подошва) → **красим, не режем**.
- Никогда: посередине руки/ноги/торса, наискось к оси конечности, волнистой поверхностью, через лицо, по тонкому месту.
- Плоскость — поперёк оси там, где деталь выходит из одежды (3–9° у профи); у корня конечности (плечо, бедро) — по месту крепления к телу.
  Спрятана под нависающий край на 1–4 мм мастера; если это дно закрытой одежды (юбка, шорты) — ровно по дну.
- Шип по умолчанию `"auto"`: гнездо туда, где вокруг стыка больше материала (у профи бывает и нога → юбка, и юбка → ноги).

**Строгая проверка каждого шва (пользователь судит именно это):**
1. Найти точное место, где **один объём переходит в другой**: ступенька или перетяжка по профилю площади вдоль оси элемента
   (`views.py --profile` по области руки/ноги/шеи) + сечение поперёк в этом месте. Плоскость — ровно на ступеньке (±0,5 мм на мастере),
   под край прятать, только если край реально нависает.
2. Сверить с переходом цвета (`colors.py`): уровни цвета и объёма должны совпасть в пределах ~1–2 мм. Расходятся — шов по объёму,
   ближайшему к смене цвета, и вынести это место вопросом в список деталей.
3. В списке деталей для каждого шва писать, **что во что входит и на какой высоте** («кисть из манжеты, z 29,5 — край манжеты на 29,7»),
   и показывать крупный разрез шва (`print/reference_examples/tools/sections.py` через стык), а не только общий вид.
4. Низкополигональная или размытая модель — честно сказать, что ступеньки нечёткие и швы приблизительные.

Типовой список для наших 40-мм фигурок: подставка · ноги/штаны (обувь отдельно только при явном крае голенища) ·
верх с рукавами того же цвета · кисти (если выходят из манжет) · лицо-маска с ушами и шеей · волосы (масса + чёлка + торчащие пряди) ·
головной убор / аксессуары.

## Порядок работы

Скрипты запускать из корня репо, `python3 print/tools/razborka_v3/<скрипт>`. Черновики — в scratchpad.

1. **Мастер**: `prep.py in.(glb|stl) master.stl [--rotz -90] [--hollow] [--up y]` → сплошной, замкнутый, 100 мм, Z вверх, лицо → −Y.
   Проверить в `views.py`, что лицо смотрит на вид `front`; если нет — подобрать `--rotz`.
2. **Цвет**: `colors.py out.png --glb src.glb` (текстура → линии смены цвета) или
   `colors.py out.png --master master.stl --ref ref.jpg --crop x0,y0,x1,y1` (референс рядом на общей сетке высот).
3. **Форма**: `views.py master.stl out.png --profile all --z ... --x=... --y=...` — края (подол, манжета, верх обуви) и перетяжки (шея, запястье).
   Для руки/ноги — `--profile x0,x1,y0,y1` по её области.
4. **Список деталей** по каталогу: что входит в каждую, цвет, чей шип, спорные места вопросом.
5. **План** `plan.json` (формат — `README.md`, пример — `examples/puffer_guy_plan.json`) → `cut.py plan.json cutdir`.
   Нет предупреждений об оторванных кусках; `scheme.png` и разрезы деталей (`print/reference_examples/tools/sections.py cutdir/master_100mm out.png "x=0" ...`) выглядят как задумано.
6. **Показать пользователю** список деталей + `scheme.png` → **ждать «да» или правки**. Без «да» не сохранять в репо.
7. **Шипы**: `keys.py cutdir outdir [40]` → проверить `keys_check.png` (шип квадратный, зазор виден, стенки целы) и `preview.png`.
   «Клей» на стыке — нормально, если места мало; несущим стыкам (голова, ноги в корпус) шип нужен — иначе поправить план.
8. **Сохранить**: `print/<имя>_parts/` — STL итогового размера, `master_100mm/`, `preview.png`, `СБОРКА.md`
   (деталь, цвет, куда, шип/клей — из `keys.json`), `python3 print/update_table.py`, коммит, пуш.

## Числа (итоговый размер, смола)

Шип: квадрат, скругление 0,3 мм, уклон стенок 4°; ширина ≈ 0,42 меньшей стороны среза (мин. 1,0 мм), высота 0,8 ширины,
но не глубже половины детали-получателя. Стенка вокруг гнезда и дно ≥ 0,6 мм. Зазоры: плоскость 0, стенки 0,10, торец 0,25
(FDM `--fdm`: 0,2 / 0,3). Подставка → подошвы: установочные шипы `kh: 0.5`. Всё это уже по умолчанию в `keys.py`.

## Частые ошибки (из первых прогонов)

- Плоскость подставки — **чуть выше** её верха (у ИИ-моделей верх неровный ±0,2 мм), иначе плёнка подставки уезжает в обувь.
- Резак без ограничения режет всё на уровне плоскости: для ног под юбкой — `prism` по их сечению, для кистей — `box` от бока корпуса наружу.
- `prism` брать там, где деталь ещё отдельна; если ниже она шире — добавить вторую область `any`.
- Голова, сросшаяся с капюшоном/воротником, — наклонной плоскостью: спереди внутри воротника, сзади над капюшоном.
- Обувь низкая (< 3 мм) — шипы сверху и снизу не влезут: предложить обувь вместе с ногами.
- Шапка, волосы, маска, капюшон на голове — стык **по форме черепа**, не плоскостью (у профи лицо↔волосы плоские лишь на 5–43 %):
  `"ellipsoid": {"c","r","outside": true}` — эллипсоид черепа подобрать по видам/сечениям. Изогнутый край шапки/чёлки — несколько
  касательных плоскостей в одной области (пересечение = выпуклый край).
- Нога, уходящая в ботинок/крокс; запястье в перчатку: `any` из двух областей + `minus` (столб ноги выше плоскости остаётся у ноги) —
  получается пробка, а ободок ботинка/перчатки остаётся на нём.
- Пряди, распадающиеся на куски, — `"seed": "all"` и соединительная полоска под краем шапки/волос (тонкий слой у черепа через `minus`).
- `prism` руки берётся там, где рука уже отделилась и от рукава, и от тела (рукав срезан наискось — отступить 2–3 мм);
  рука, прилегающая к телу, — ошибка модели: просить отвести или резать `cyl`.
- Пример полного плана со всеми приёмами — `examples/emm_plan.json` (Эмм, 13 деталей), `examples/emm_v2_plan.json`, `examples/suit_guy_plan.json`.
- **Полая модель с дренажами** (старые печатные STL): `prep.py --fill-cavity 3.4` — полости находятся «взглядом» по осям, щели между ногами не трогаются.
- **Низкополигональная / ступенчатая сетка**: `prep.py --smooth 8–12` (Луп + Таубин) — гладко и плотно (пользователь хочет высокополигональные гладкие модели).
- Тонкая накладка (оправа очков, галстук, пуговицы) < ~0,5 мм на итоговом размере — роспись, не деталь.
- Модель, собранная в коде, — мастер = её STL как есть (без `prep.py`, он центрирует по габаритам и сдвинет координаты плана).
- **Есть старая разборка по цветам** (старые детали в сборе): склеить их → `prep.py --fill-cavity --smooth` = гладкий мастер;
  старые детали = карта цветов: границу «волосы/кожа» подогнать плоскостью по точкам смены детали, мелкие детали (кисти) брать
  областью `"mesh": {"path": старая.stl, "scale": 1.15}` + плоские срезы по манжетам. Пример — `print/redhead_kit/plan.json`.
- Слипшаяся генерация (сидит, обхватив колени): один цвет = одна деталь; не резать плоскостью, если она проходит сквозь колени/руки.
